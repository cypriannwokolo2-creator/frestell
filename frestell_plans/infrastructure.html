Infrastructure — Docker, Nginx, Terraform, Monitoring, CI/CD

infrastructure/ — Core Infrastructure as Code

infrastructure/
  docker-compose.yml (dev environment)
  docker-compose.prod.yml (production)
  docker-compose.staging.yml (staging)
  .dockerignore
  
  nginx/
    nginx.conf (main config), mime.types
    conf.d/
      default.conf (routing rules), api.conf (API upstream), websocket.conf (WebSocket)
    ssl/
      params.conf (SSL/TLS parameters)
  
  docker/ (Dockerfile collection for services)
    Dockerfile.api, Dockerfile.web, Dockerfile.ai, Dockerfile.payments, Dockerfile.blockchain, Dockerfile.chat
  
  scripts/
    deploy-prod.sh (production), deploy-staging.sh (staging)
    backup-db.sh (backup routine), restore-db.sh (restore), ssl-renew.sh (Let's Encrypt)
  
  monitoring/
    prometheus.yml (metrics scraping), alertmanager.yml (alert routing)
    grafana-dashboards/
      api-overview.json, business-metrics.json, stellar-monitor.json
  
  terraform/ (IaC for cloud infrastructure)
    main.tf, variables.tf, outputs.tf
    modules/
      vps/ — VPS setup
      database/ — PostgreSQL/RDS

Key Decisions

  • docker-compose for dev; Kubernetes or Docker Swarm for prod
  • Nginx as reverse proxy & SSL terminator
  • PostgreSQL + Redis (caching/sessions)
  • Prometheus + Grafana for observability
  • Terraform for repeatable cloud deployments
  • CORS config in nginx & API
  • Environment-based configs (dev, staging, prod)
