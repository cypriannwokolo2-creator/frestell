Contracts — Rust / Soroban Smart Contracts

Contains Soroban contracts for escrow, disputes, and token operations. All are Rust-based, built with cargo and deployed to Stellar testnet/mainnet.

Workspace Root

contracts/
  Cargo.toml (workspace manifest)
  Cargo.lock
  rust-toolchain.toml
  Makefile
  README.md
  .gitignore

contracts/escrow/ — Escrow Contract (Hold Funds, Release on Milestone)

contracts/escrow/
  Cargo.toml, Cargo.lock, rust-toolchain.toml
  Makefile, README.md
  
  src/
    lib.rs (contract entry point)
    contract.rs (main escrow logic)
    storage.rs (Soroban storage map definitions)
    errors.rs (contract error codes)
    events.rs (contract event emissions)
    types.rs (data structures)
    auth.rs (authorization logic)
    interface.rs (contract interface)
    admin.rs (admin functions)
  
  tests/
    test.rs, integration_test.rs
    common/
      mod.rs, setup.rs, fixtures.rs
  
  scripts/
    deploy.sh, deploy_testnet.sh, deploy_mainnet.sh
    initialize.sh, upgrade.sh, verify.sh, invoke.ts
  
  bindings/ (Generated TypeScript bindings from contract)
    escrow.ts, types.ts, errors.ts
  
  optimizations/
    wasm-opt.sh, size-report.txt

CI/CD for Contracts

In your `.github/workflows/`, ensure you have:

.github/workflows/
  ci-contracts.yml
    - on: pull_request path filter (contracts/**)
    - cargo test, cargo build --target wasm32-unknown-unknown
    - cargo clippy, cargo fmt check
    - WASM size reporting
contract.rs scripts/ dispute/ token/ shared/ workspace-level Cargo.toml

CI notes

  • Install Rust toolchain + target wasm32-unknown-unknown
  • Run cargo test and wasm-opt size checks
  • Generate bindings for JS (bindings/ folder) consumed by backend
