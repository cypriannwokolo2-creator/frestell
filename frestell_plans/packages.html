Packages — Shared Types, DTOs, Validators, Utilities

Keep DTOs, Zod schemas, Prisma client, and shared types here to avoid duplication between apps and services.

packages/
  shared/
    package.json, tsconfig.json, index.ts
    
    src/
      index.ts
      
      types/ — TypeScript types for all domains
        index.ts
        user.types.ts, auth.types.ts, job.types.ts, proposal.types.ts
        contract.types.ts, dispute.types.ts, chat.types.ts, payment.types.ts
        stellar.types.ts, review.types.ts, notification.types.ts, admin.types.ts
        common.types.ts, api.types.ts
      
      validators/ — Zod schemas for runtime validation
        index.ts
        zod-schemas.ts (exports all schemas for easy importing)
        auth.schema.ts, job.schema.ts, proposal.schema.ts
        contract.schema.ts, user.schema.ts, payment.schema.ts
        stellar.schema.ts, common.schema.ts
      
      dtos/ — Data transfer objects (for API contracts)
        index.ts
        auth.dto.ts, user.dto.ts, job.dto.ts, proposal.dto.ts
        contract.dto.ts, dispute.dto.ts, chat.dto.ts, payment.dto.ts
        review.dto.ts, admin.dto.ts, notification.dto.ts, search.dto.ts
      
      utils/ — Shared utility functions
        index.ts, helpers.ts, formatters.ts, validators.ts
        constants.ts, errors.ts, stellar-helpers.ts
        date-utils.ts, string-utils.ts, number-utils.ts
      
      enums/ — Shared enumerations
        index.ts
        user-role.enum.ts, job-status.enum.ts, proposal-status.enum.ts
        contract-status.enum.ts, dispute-status.enum.ts, verification-tier.enum.ts
        payment-status.enum.ts, notification-type.enum.ts
      
      interfaces/ — Shared TypeScript interfaces
        index.ts, paginated-response.interface.ts, api-response.interface.ts
        stellar-transaction.interface.ts, socket-event.interface.ts
      utils/
    package.json
    tsconfig.json
  ui/
  analytics/

Recommendation: place `prisma/schema.prisma` here or at repo root (`prisma/`) if multiple projects consume the generated client. Always import DTOs from `packages/shared` in backend and frontend.
