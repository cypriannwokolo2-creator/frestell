# Architecture Decision Records

This directory contains ADRs for FreStell. Each ADR is a short, numbered Markdown file that captures a single, important architectural decision: its context, the choice we made, and the consequences.

| #    | Title                                     | Status   | Date       |
| ---- | ----------------------------------------- | -------- | ---------- |
| 0001 | Modular Monolith → Service Split Strategy | Accepted | 2026-06-06 |

## ADR lifecycle

- **Proposed** — written, under review.
- **Accepted** — chosen; binding.
- **Superseded** — replaced by a later ADR (link must point to the new one).
- **Deprecated** — no longer relevant.

## Format

We follow the classic Nygard template: Title → Status → Context → Decision → Consequences → Alternatives → References.
